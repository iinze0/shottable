# ShotTable

Client-side screenshot / image of a table → editable grid + CSV.

Drop a clear screenshot of any table (bank statement, report, form, research paper). OCR runs entirely in the browser with Tesseract.js. Nothing is uploaded.

## Why

People still manually type tables out of screenshots because existing tools either require uploading the image or produce messy results that need heavy cleanup.

## Features

- Drag & drop image
- Client-side OCR
- Editable table
- Download or copy CSV
- No account, no upload

## Usage

Open `index.html` in a modern browser. Works best with high-contrast, reasonably straight tables.
